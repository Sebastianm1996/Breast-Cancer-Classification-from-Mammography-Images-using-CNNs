# Mammography Image Classification with CNNs

## About the Project

This project was developed for the **Machine Learning (Aprendizaje Autónomo)** course as part of the **Data Science Program at Tecnológico de Costa Rica (TEC)**.

The main objective was to learn and apply the basic concepts behind convolutional neural networks (CNNs) by building a binary image classification model using mammography images.

The project was mainly an opportunity to experiment with the complete process of preparing image data, building neural network architectures, training different models, and evaluating their performance.

## What I Worked On

During the project, I explored different parts of an image classification workflow, including:

* Loading and exploring an image dataset
* Image preprocessing and resizing
* Building convolutional neural networks
* Training and validation
* Data augmentation
* Working with class imbalance
* Using class weights and different balancing approaches
* Comparing different model architectures
* Evaluating model performance using different metrics

Several versions of the model were tested throughout the notebook to understand how changes in the data preparation and network architecture affected the results.

## Tools

The project was developed mainly using:

* Python

The image dataset is not included in this repository due to its size.

## Project Status

This is the original basic version developed for the course and is not intended to represent a finished or clinically validated model.

There are several areas that could still be refined, including the model architecture, evaluation methodology, preprocessing pipeline, and overall organization of the notebook.

For now, the repository is intended to document the work completed during the course and the concepts I learned while developing my first image classification models with convolutional neural networks.
